## [9.0.0](https://github.com/DennisPohlmann/AWStats/compare/v8.0.0...v9.0.0) (2026-11-08)

### ⚠ BREAKING CHANGES

* the Webmin and Dolibarr modules, the rpm/tgz/PAD
packaging and the PDF documentation are no longer part of AWStats. The
web interface API answers only to localhost, IP addresses and the
names in AWSTATS_ALLOWED_HOSTS, so a reverse proxy that passes the
original Host header (HAProxy) needs that variable set.
